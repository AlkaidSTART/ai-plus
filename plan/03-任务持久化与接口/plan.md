# 阶段 03：任务持久化与接口

## 目标与前置条件

实现“提交任务 → 原子落库 → 可查询快照”的最小 API 闭环，落实幂等、输入规范化和资源范围检查。依赖 [阶段 01](../01-基础配置与迁移/plan.md)，不依赖外部模型或阶段 02 的付费验证。

先读 `docs/api.md` §1–4、§7，`app/api/`、`db/models.py`。本阶段仅本地隔离开发；真会话鉴权在阶段 08，对外服务前必须完成。

## 文件范围

已有：`backend/app/api/routes/tasks.py`、`api/schemas.py`、`api/errors.py`、`api/deps.py`、`app/main.py`、`db/models.py`、`db/session.py`。

拟新增：`backend/app/services/tasks.py`、必要增量迁移、`backend/tests/test_tasks.py`、`backend/tests/test_task_isolation.py`。测试通过应用依赖覆盖注入可信租户，不在产品接口增加任意 tenant 选择能力。

## 实施步骤

- [ ] 去掉 x-tenant-id 对身份的决定权。本地预置身份仅来自可信服务端配置，生产模式默认拒绝使用预置身份；路由真正注入租户、项目和数据库会话依赖。
- [ ] 补缺失/非法输入的统一错误处理，覆盖 body、header、path、query；request_id 按请求关联，不再固定 req_todo，不返回内部堆栈。
- [ ] ASIN 先校验与大写规范化，再去重检查 1–10 个；单个非法 ASIN 使整个请求失败。稳定化 ASIN 集合表示，明确次序不影响幂等哈希。
- [ ] 校验日期窗正序、结束日不在未来；按已确认站点时区和六个日历月默认口径解析短月/边界，保存实际解析窗。不要用固定天数替代日历月。
- [ ] 明确缺省输入的幂等处理：重放相同键的默认日期请求不能因站点日期变化产生新任务；哈希定义区分客户端提交意图和首次冻结的解析结果，必要时先补充并确认契约说明。
- [ ] 验证项目属于当前租户和站点，使用合法 UUID 映射；用户给定 tenant 或 model 输出都不能参与授权。
- [ ] 在同一事务写 Task、Product/TaskItem 和首个 task.updated 事件；利用数据库唯一约束处理并发同键请求，同内容返回原 task，不同内容 409，失败回滚不残留半份任务。
- [ ] 增加契约需要但 ORM 没有的最小持久字段，如完成时间、parent_task_id、分项错误/警告与一致快照所需状态。按已批准迁移策略增量修改，不提前加入财务字段。
- [ ] GET 列表按租户、project/status 过滤与 created_at/id 稳定排序，cursor 绑定过滤条件，验证默认/最大 limit；拒绝非法游标。
- [ ] GET 详情在一致性读快照中取得 task/items 与 last_event_id，不能将新事件游标拼到旧状态。无结果 report_id 保持 null，节点未运行不伪造进度。
- [ ] retry 仅接受已终结源任务中 FAILED 的非空分项集合，创建关联 parent_task_id 的新任务，保留源失败历史；复用创建幂等服务，不复用旧 task ID。
- [ ] cancel 对活动任务原子保存首次取消标记，对终态返回原状态。worker 落实取消和发布竞态由阶段 04 接手，本阶段不谎报“已停止外部调用”。
- [ ] response schema 与 OpenAPI 显式覆盖已实现路径，未实现的报告/SSE 继续明确 501，不能用空数组伪装实现。

## 验证与验收

```bash
cd backend
uv run pytest -q tests/test_tasks.py tests/test_task_isolation.py
uv run pytest -q
```

数据库测试使用隔离 PostgreSQL，不用 SQLite 代替 UUID、约束和事务并发语义。

- [ ] 并发同键同输入只产生一个任务及一组分项；同键不同输入 409，不串租户。
- [ ] 大小写、重复 ASIN、去重前超过 10 但去重后合法、非法格式、日期窗/短月/缺省窗重放都可复现。
- [ ] 不存在/其他租户项目、任务、分项统一按契约拒绝；伪造 x-tenant-id 不改变身份。
- [ ] 分页无重复漏项，cursor 不能跨过滤条件使用；无任务返回空列表。
- [ ] 同一事务失败后无残留业务行或孤立事件；并发详情快照与游标一致。
- [ ] 取消请求幂等；人工重试新建任务并保存关联，拒绝活动/非失败分项。

## 非目标与停止条件

不调用模型、不执行 worker、不假造报告，不新增项目管理平台或登录接口。未确定租户来源、日期语义或并发幂等保证时，先确认再继续。
