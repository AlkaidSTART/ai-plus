# 阶段 14：云端模型接入（Vercel AI SDK）

## 目标与前置条件

把文本链路的模型方向从本地 bge-m3 推理改为云端 API：向量与文本生成统一经
Vercel AI SDK（Python 版）调用，模型选型、用量成本与质量门槛先验证再冻结，
供阶段 06/07 实现消费。

依赖 [阶段 01](../01-基础配置与迁移/plan.md) 的可运行环境。本计划只覆盖选型、
网关封装与向量维度迁移；片段切分、聚类算法、建议生成逻辑仍归阶段 06/07。
实施前必须先拿到：云端 embedding 模型 ID、文本模型 ID、网关或直连方式、
调用预算与限流、质量验收阈值。真实调用与密钥发放另需明确授权。

## 当前事实

- 仓库尚无任何本地或云端模型实现：无 torch/transformers、无 bge-m3 调用、
  无 LLM 生成、无 LangGraph 集成（阶段 02 已核实）。本次是方向变更，
  不是替换已有本地代码。
- 技术方案 §5.2 与阶段 02/06 当前假设本地 bge-m3：Dense 1024 维、单进程装载、
  换模型不复用向量。这些假设在本阶段被替代，不是并存。
- Vercel 已发布官方 Python 版 AI SDK（公开 beta，要求 Python 3.12+，
  `uv add ai`，默认走 AI Gateway，以 `AI_GATEWAY_API_KEY` 鉴权）；
  embeddings 支持 `embed`/`embedMany`（OpenAI、Mistral、Voyage 等提供方，
  Python 端提供方对等性待实施时按安装版本核实）。
  AI Gateway 另有 OpenAI 兼容 REST（含 `POST /embeddings`），可用已有
  `httpx` 依赖直调，作为 SDK beta 不稳定时的零新增依赖兜底。
- 方向变更的最大连带影响：阶段 01 已冻结 `review_fragments.embedding`
  为 `Vector(1024)`。云端向量维度若不是 1024，必须新增独立迁移修改该列，
  不能改写已冻结的 0001。
- 本地 Python 为 3.12，满足 SDK 的版本下限；网关与模型版本必须以实施时
  安装包与官方文档为准，不凭记忆编写接口。

## 实施步骤

- [ ] 按安装版本的 `ai` 包源码核实 `embed`/`embedMany`/文本生成的真实签名、
  超时、重试、流式与结构化输出支持，记录包版本与官方文档链接；beta 变更
  风险写入遗留事项。
- [ ] 确认 embedding 模型 ID（含维度、修订号锁定方式）与文本模型 ID
  （含版本、结构化输出能力），明确走 AI Gateway 还是直连提供方；
  未确认前不写任何模型 ID 到代码或文档。
- [ ] 落实网关封装的纯契约：错误映射沿用阶段 02 分类（401/403 永不重试，
  429/5xx/超时有限退避，总尝试上限不变）；向量复用键绑定原文哈希、
  切分版本与模型修订号；每次调用记录模型标识、用量与耗时，密钥与完整
  输入输出不得进日志。
- [ ] 有凭证与预算后执行一次真实 embed，断言返回维度等于选型维度；
  执行一次真实文本生成，验证结构化输出与超时行为；记录耗时、计量与
  实际账单区别。无凭证默认不执行，不把离线测试当调用证据。
- [ ] 用阶段 02 评估集复测跨语种近义、误合并、伪造引用拒绝，确认云端方案
  达到阶段 02 既定质量门槛；阈值、单例处理、严重度聚合规则有变化时先确认。
- [ ] 编写并评审向量维度迁移（新增文件，不碰 0001）：修改目标列类型、
  说明旧数据处理（当前无线上向量数据，只需保证空库与测试库路径），
  离线 SQL diff 只接受预期变更；阶段 06 的 HNSW 索引按新维度重建，
  不复用旧维度假设。
- [ ] 更新技术方案 §5.2 与阶段 02/06/07 的消费契约：调用方式、版本锁定、
  复用键、成本与错误边界；废弃“单进程装载 / 独立推理服务二选一”旧决策，
  保留评估集与质量门槛。
- [ ] 全链路回归：`uv sync --frozen` 可复现，现有测试不受新依赖影响；
  引用 `EMBEDDING_DIM` 的位置与迁移目标一致，没有硬编码 1024 残留。

## 验证与验收

```bash
cd backend
uv sync --frozen
uv run pytest -q tests/test_model_gateway.py
uv run pytest -q
```

- [ ] 无凭证环境默认跳过真实调用测试，跳过原因明确；有凭证时单次调用
  可复现维度、耗时与费用记录。
- [ ] 错误映射、复用键、计量与脱敏有离线测试；401 不重试、上限不突破。
- [ ] 迁移在隔离库可重放，重复执行无副作用；离线 SQL diff 与评审一致。
- [ ] 评估集质量门槛达标或如实记录差距；未达标不进入阶段 06/07 的云端实现。
- [ ] 技术方案与阶段文档只写已验证结论，未确认的提供方对等性、价格与
  性能数字不写入。

## 非目标与停止条件

不实现视觉、财务、回测，不在前端调用模型（密钥不出后端，租户与证据链
设计不变），不发放生产密钥，不做批量历史向量回填（尚无历史向量）。
模型 ID、预算、质量阈值任一未确认即停止实现，只保留调查结论；
SDK beta 导致接口漂移时优先用 httpx 直调兜底，不为追新重写封装。

## 交接

向阶段 06 提供：网关调用方式、锁定模型版本、向量维度、复用键、评估结论
与成本边界；向阶段 07 提供：文本模型版本、结构化输出契约、错误与超时语义。
本阶段不替 06/07 决定聚类阈值与建议模板，未决项保持未决。
