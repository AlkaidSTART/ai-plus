# 阶段 08：鉴权隔离与 P0 验收

## 目标与前置条件

使真实文本后端具备可对接的身份、企业隔离、恢复与部署验证证据。依赖 [阶段 07](../07-双栏建议与证据报告/plan.md)；对外访问前必须完成本阶段安全门禁，不能把前期预置开发身份暴露公网。

读取 `docs/技术方案.md` §6、§9 和 `docs/api.md` 全部 P0 契约。身份方案、成员授权矩阵、事件/缓存/数据保留策略及目标部署环境须先明确确认。

## 文件范围

已有：`backend/app/api/deps.py`、各业务路由、`app/main.py`、`config.py`、数据库模型和必要迁移、API/worker/service 日志、Dockerfile、Compose、backend README、`docs/api.md`。

拟新增：确认身份方案后的最小会话验证模块与必要端点、`backend/tests/test_auth.py`、`test_tenant_isolation.py`、`test_p0_acceptance.py`、必要的压力/故障验证入口。不得默认新建完整用户管理系统。

## 实施步骤

- [ ] 确认使用既有身份提供方还是最小本地会话实现，先冻结登录、登出、失效及项目启动信息契约；不能在当前不存在的身份 API 上凭空调用。
- [ ] 使用可验证服务端会话获得 tenant/membership，按已确认方式设置 HttpOnly/Secure/SameSite 与过期撤销；不接受 localStorage mock token 或 x-tenant-id 决定身份。
- [ ] 状态变更接口落实 CSRF token 与 Origin 校验；EventSource 使用可验证 cookie 会话，不把长期令牌写 URL。跨域凭据必须在目标浏览器与部署方式验证。
- [ ] 补 API、报告、证据、取消、重试及 SSE 的完整资源链授权；流建立后会话失效需关闭，重新连接不能降级为匿名。
- [ ] 测试至少两个企业、同企业多个项目/任务的越权边界，覆盖列表泄漏、ID 混用、关联表误绑、事件补发和 worker 持久 tenant 上下文。
- [ ] 落实来源/模型调用额度和请求限流、超时与成本上限；具体阈值依据阶段 02/业务确认，不能随意添加无依据的默认阈值。
- [ ] 建立最小结构化日志：request/task/item/node/attempt/模型版本、耗时、重试、来源覆盖与调用计量；默认不记录密钥、完整评论或敏感输入。
- [ ] 校核 API/worker/迁移与数据库就绪的部署顺序、明确可失效 Redis 行为，生产缺必要配置时失败关闭。生产密钥不沿用开发密码，构建版本可复现。
- [ ] 执行 worker 重启、租约竞争、取消竞态、重复提交、数据库短暂不可用、Redis 丢失、SSE 重连/过期游标等故障测试。
- [ ] 使用独立数据库做备份恢复演练；任何破坏性演练仅限获授权测试环境，不触碰真实业务数据。
- [ ] 固定数据规模/并发/硬件，实测查询 P95、带过滤向量检索召回与耗时、冷/热缓存链路耗时、SSE 提交到客户端接收延迟及每任务成本，分别对照 PRD 目标；后端接收延迟不能冒充浏览器展示延迟。
- [ ] 逐项核对 OpenAPI 和 api.md 八个业务端点，提供 curl/客户端调用示例、错误/空态/SSE 恢复样本。文档只标注验证过的能力，不把版本目标写成运行事实。

## 验证与验收

```bash
cd backend
uv run pytest -q tests/test_auth.py tests/test_tenant_isolation.py tests/test_p0_acceptance.py
uv run pytest -q
```

Compose 构建、启动及迁移须先确认目标环境和授权，不把实施计划理解为生产部署许可。

- [ ] 未登录 401、跨企业资源 404、CSRF/Origin 拒绝、会话过期流关闭、预置身份生产禁用均通过。
- [ ] 真实七节点闭环、部分失败、合法空样本、重试保留历史、恢复和取消竞态全部有自动化证据。
- [ ] 任一费用/性能目标未达标时提供实际测量与限制，不能宣布达到 SLA；单机演示不等于生产可用性证明。
- [ ] 后端 HTTP 客户端可复现全部协议。若本阶段未获前端改动授权，不修改 frontend；浏览器 Cookie/SSE/ECharts 与 `bun run build` 留给独立前端联调任务，不将后端验收等同完整 P0-04 验收。

## 非目标与停止条件

不重构前端、不自动部署公网、不加 P1/P2，不新增监控平台全家桶。身份方案、敏感数据保护或生产权限未落实则保持“仅本地开发可用”，不能跳过安全门禁。

## 交接

给前端及后续阶段交付已验证契约、会话/CSRF 使用说明、演示入口、数据范围和已知限制；P1/P2 复用现有租户与报告版本边界，不重建另一套认证或事件协议。
